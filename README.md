# DocMate-App
Doctor Appointment &amp; Consultation system as Android App That Help clients to get help in Quick Way 

## Setup
1. Create a Firebase project and add an Android app with package `com.example.docmate`.
2. Download `google-services.json` and place it in `DocMate/app/`.
3. Enable Email/Password and Google sign-in in Firebase Auth, and create a Firestore database.
4. Open the `DocMate` folder in Android Studio and run.
